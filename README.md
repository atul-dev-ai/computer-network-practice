This repository contains my **Computer Network practice files** created using **Cisco Packet Tracer**.

## 📌 About

I am using this repository to store and organize my networking practice, lab exercises, and Cisco Packet Tracer (`.pkt`) files.

## 🛠️ Tool Used

* **Cisco Packet Tracer**
* Networking concepts and protocols

The repository may include practice files related to:

* Basic Network Configuration
* IP Addressing
* Subnetting
* LAN & WAN
* VLAN
* Inter-VLAN Routing
* Static Routing
* Dynamic Routing
* DHCP
* DNS
* NAT
* ACL
* Network Devices Configuration
* Other Computer Network Lab Practices

## 🎯 Purpose

The main purpose of this repository is to:

* Practice computer networking concepts
* Build and test network topologies
* Keep all Packet Tracer practice files organized
* Track my learning progress using Git and GitHub

## 📁 File Format

All network simulation files are primarily saved in:

```text
.pkt
```

These files can be opened using **Cisco Packet Tracer**.

## 🚀 How to Use

1. Clone or download this repository.
2. Open the `.pkt` file using Cisco Packet Tracer.
3. Explore the network topology and configurations.
4. Modify the topology and configurations to practice.
